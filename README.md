# Starbucks Menu Directory (Independent Guide)

A high-performance, modern web application that provides a searchable catalog of Starbucks coffee, drinks, breakfast options, and bakery items along with calories and pricing estimates.

## Features
- **Dynamic Live Search**: Filter drinks and food in real-time.
- **Category Navigation**: Instantly filter by Hot Coffee, Cold Brew, Frappuccino®, Breakfast, and Bakery.
- **Product Detail Modal**: View calorie counts, dietary specs, and enlarged visuals.
- **Mobile First UX**: Optimized responsive navigation drawer, smooth scrolling, and touch-friendly controls.
- **SEO & Schema Optimized**: Includes JSON-LD structured data and meta specs.

## Deployment
1. Upload all repository files to any static server or host (e.g., Vercel, Netlify, GitHub Pages).
2. Update the `https://starbucks-blush-seven.vercel.app/` placeholder inside `index.html`, `sitemap.xml`, and `robots.txt` with your actual live domain URL.
